# SpendWise – Student Budget Tracker

## Run locally

1. Extract SpendWise.zip.
2. Open a terminal in the extracted SpendWise folder.
3. Run `python -m http.server 8000` (or `python3 -m http.server 8000`).
4. Open http://localhost:8000. Use **Try demo** for sample data and **Exit demo** between testers.

## Host on GitHub Pages

1. Upload the contents of the SpendWise folder to the root of your repository. Keep the art folder intact.
2. In the repository, open Settings → Pages. Choose Deploy from a branch, select your branch (usually main) and /(root), and save.
3. Open the published URL shown in the Pages settings.

The site uses plain HTML, CSS, and JavaScript. Budget and expense entries are stored in the current browser for each site address. Demo changes are temporary.

Edit index.html for the layout, style.css for the design, and app.js for the application logic. The art folder contains the panel and dashboard backgrounds. The piggy-bank logo comes from the supplied Spendwise reference archive.
